## LMS and Course

- Course: a travel or learning course shown to users.
- Chapter: a section inside a course.
- Quiz: assessment attached to a course.
- Progress: a user's learning progress for a course/chapter.
- Certificate: PDF certificate issued after course completion.
- Review: user review for a course.
- Qna: user question and answer thread for a course.
- Diagnosis: questionnaire and recommendation flow for course suggestions.
- My Course: user's enrolled or owned course view.

## Benefit

- Coupon: benefit policy or issued discount/benefit for a user or course.
- Mileage: user reward point or mileage history.
- Course Reward: reward issued after course-related events.
- Course Reward Failure: failed reward issue record that may need retry.

## User and Admin

- User: normal service member.
- Admin or Manager: operator account used for admin APIs.
- Auth: login, signup, session, token refresh, logout, and email verification behavior.

## Travel

- Accommodation: lodging product or lodging detail.
- Package: travel package product.
- Booking: reservation made by a user.
- Refund: refund request or admin refund handling.
- Flight: external flight information/API domain.

## Community

- Post: community content created by a user.
- Comment: reply on a community post.
- Report: user report against inappropriate content or behavior.
- Notice: public or admin-managed notice content.

## Communication

- Chat: user chat room and message behavior.
- Chatbot: AI chatbot questions, knowledge, suggested questions, and history.
- Inquiry: customer inquiry submitted by a user and answered by admin.
- Friend: user friend relation, request, block, and search behavior.
